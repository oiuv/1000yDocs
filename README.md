# 千年游戏开发手册

本仓库收录炎黄新章的玩家资料、服务端技术说明和脚本开发参考。按阅读目的选择入口：

| 阅读目的 | 从这里开始 |
|---|---|
| 查任务、地图、装备、武功与职业技能 | [炎黄新章游戏资料](help/炎黄新章游戏资料/README.md)；本服规则见[云端千年](help/炎黄新章游戏资料/云端千年.md) |
| 配置和维护服务端 | [技术资料总目录](help/README.md)，包含运行参数、数据表、GM 命令和维护约束 |
| 编写 NPC、任务或物品脚本 | [脚本开发入门](Script.md)，按语法、绑定、接口和完整示例逐步查阅 |
| 理解源码、协议与持久化 | [系统架构](help/architecture.md)、[通信协议](help/protocol.md)、[玩家数据库](help/database.md) |
| 快速了解整个项目 | [HTML 项目概览](project-analysis-report.html) |

## 常用查阅

- [GM 管理命令](help/GMCommands.md)：权限、参数、影响范围及实现限制。
- [地图传送机制](help/Teleportation.md)：固定、随机、条件、多人投物及脚本传送。
- [配置编号、索引与固定容量](help/ConfigurationIdentifiers.md)：改号前核对行序、固定用途和存档限制。
- [常量索引](help/constants/README.md)与[特殊物品机制](help/SpecialItems.md)：枚举取值和按内部名称处理的行为。
- [统一术语表](help/TERMINOLOGY.md)：源码英文名与游戏中文名的对应。

## 目录分工

| 位置 | 内容 |
|---|---|
| `help/炎黄新章游戏资料/` | 面向玩家的玩法说明；官网与本服资料须留意各页适用版本 |
| `help/` | 面向维护者的架构、协议、配置表、机制说明及公开源码镜像 |
| `procedure/`、`function/` | 脚本过程事件与有返回值的事件，按事件单独查阅 |
| `print/`、`callfunc/` | 游戏脚本命令与查询函数，按接口单独查阅 |
| `Script/` | 云端千年神武奇章线上优化版脚本归档；[移植前先核对版本](Script/README.md) |

## 公开源码与资料边界

- [Cl1000 客户端源码](https://github.com/oiuv/Cl1000)：原生客户端、窗体、收发包及配套依赖。
- [TGS1000 游戏服务器源码](https://github.com/oiuv/TGS1000)：游戏世界、角色、物品、战斗和脚本处理。

两者作为炎黄新章的公开源码参考基线，源码位置及引用方式见[公开源码与引用说明](help/source-reference.md)。源码基线、历史运营脚本和目标服务器的实际部署配置应分别核对。

技术资料面向官方源码的通用机制；额外客户端辅助、Python 工具与私有运行记录不在此公开文档范围内。新增说明应进入对应主题页并补充索引；同一字段或接口的完整定义集中维护，入门页通过链接引用。
