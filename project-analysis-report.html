项目概览

项目为炎黄新章的 Delphi 7 客户端与分布式服务端源码。客户端经 Balance 获取 Gateway，再由 Gateway 接入登录、付费校验、角色数据库与游戏服务。本文说明官方源码能够证实的行为，不把运营版本定制或未提供实现的外部服务当作通用游戏规则。

编译成功、页面齐全和文件存在分别只证明构建、索引及资料存在；它们不等于全部加载分支正确，也不等于完整实机验收。

服务模块与连接方向

Client → Balance → Gateway → Login / DB / Game / Paid
                    ↑
             Gate 状态 → Balance（UDP）
组件常用入口职责
BalanceTCP 3053；接收 UDP 3030按可用 Gateway 连接数返回地址。TCP 3000 管理监听不证明当前 Gateway 使用该路径。
GatewayTCP 3054版本校验、登录阶段、后端连接及游戏消息转发；不是游戏逻辑主机。
LoginTCP 3050SDB 与 SQL 两种账号后端；配置、依赖和接入检查必须按所选实现核对。
DBTCP 3051角色数据持久化；管理与物品接口同样应保持私有。
Game / TGSTCP 3052地图、实体、战斗、物品、脚本及角色状态；向 DB 发送角色保存。
付费后端以 Gate 配置为准启用计费时校验付费状态。源码配置存在 3049、5999 两种缺省值，不可混用。

角色列表在付费查询之前返回；启用付费校验时，付费确认后才能完成角色接入。TGS 内部 TfrmGate 是游戏服务内部组件，不等于外部 Gateway；角色保存走 TGS 的 DB 连接。

日志与外部服务

UDP 日志端口包括 ITEM 6001、MOUSEEVENT 6010、MONITER 6011、CONNECT 6022、PAY 6000、OBJECT 3003、RELATION 3005，实际目标地址以 sv1000.ini 为准。Battle、Notice 仅说明已提供的连接配置和调用接口，不推断未提供实现的内部行为。

通信、状态与数据加载

  • 整数按 Delphi packed record 的小端布局解析，固定字符串保留字段宽度、零填充与 GBK/CP936。
  • 客户端 TCP 使用自定义加密及帧边界，不是 TLS；收发必须处理拆包和粘包。连接版本取启用的 PROGRAM_VERSION，当前共享源码为 40，其他部署仍须核对实际 Gate。
  • 客户端与 Gate、以及 Gate 的 Login/DB/Paid 后端路径须按各自封包实现核对；Gate 与 Game 的路径不能机械套用客户端加密层。
  • 移动具有客户端预测与服务端校正；本地位置不等于每一步均有服务端确认。客户端状态校验应依据 SM_NETSTATE、CM_NETSTATE 的实际结构和 CRC。
  • 保存队列每 10 个 tick（100ms）尝试发送一项，成功后移除；周期保存 rEnd=1 对应 DB_UPDATE_END。
  • Init、Setting、脚本索引和 help 窗口分别有加载入口；脚本语法、事件上下文及返回值须按解释器和分派器判断。

数据表字段名不能替代实际计算：武功耗能、物品条件、附加属性、制造和地图连接均须同时核对加载器及消费点。目录中的备份、未索引脚本或注释掉的加载代码不应写成可用功能。

安全与维护注意事项

  • 公网仅开放 Balance 与 Gateway；Login、DB、Game、付费后端、管理接口和 UDP 接收端必须限制来源。
  • SDB Login 不调用 IP 检查器，DB/SQL Login 缺少 IPList.txt 时放行全部来源；不能用配置文件代替网络隔离。
  • Gate 心跳计时未更新、限包环形槽覆盖过快，不能将现行实现描述成严格三秒心跳或可靠一秒限包。
  • 加密发送临时缓冲区限制、随机事件编号越界、婚姻记录、名单加载路径及矿物结构清零等已确认风险见源码校核页；说明风险不代表修复程序。
  • 原始 SDB/TXT、脚本与 Delphi 源文件保留 GBK/CP936 和 CRLF。Markdown/HTML 使用 UTF-8，不改写作为证据保留的原始资料。
  • 公开资料不包含凭据、玩家记录、运行日志、数据库和未经授权新增的源码；示例使用脱敏地址和账号。
