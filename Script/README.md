# 云端千年神武奇章线上优化版脚本归档

本目录保存实际运营的“云端千年神武奇章”服务器脚本，供阅读和流程参考。该版本以原版神武奇章核心玩法为基础，并加入运营优化；活动、奖励、对象配置和文案可能属于云端定制，不能据此反推原版神武奇章或炎黄新章的行为。

## 归档与目标版本

- 本目录的脚本及 `Script.SDB` 是历史运营实例，保留归档内容；修正文档不等于修改归档脚本。
- 目标服务器的 `Script/`、`Init/`、`Setting/` 等运行目录决定实际配置。炎黄是后续版本，同名脚本仍可能有不同玩法和接口。
- 接口和语法分别以目标版本的 `uScriptManager.pas`、`ScriptCls.pas`、`Common/ScriptBasic.pas` 为准。[公开源码引用说明](../help/source-reference.md)提供可独立查阅的源码入口。

SDB/TXT 保留原始 **GBK/CP936** 编码，本资料库统一使用 **LF** 换行。不要批量转换编码；与实际运行资源比较时应忽略 LF/CRLF 差异。

## 已知迁移注意事项

- `龙师父.txt` 使用 `getjobgrade`。公开分派器没有该查询分支；读取触发玩家职业等级应核对 [`getsenderjobgrade`](../callfunc/玩家属性函数/getsenderjobgrade.md)。
- 部分归档脚本向 `getrandomitem` 传入 4、5。编号能否使用取决于目标程序分配的奖池容量与加载范围，不能以配置文件存在为依据；详见[随机物品池](../help/Event.md#randomeventitemsdb)。
- `绣球.txt` 保留两处将普通文本直接交给 `print` 的用法。`print` 只分派命令，移植时应改为相应的消息命令，不能照搬这两处文本输出。
- 命令及参数之间需要正确分隔，例如 `say 文本`；有效语法和命令名称分别见[脚本语法](../help/Pascal.md)与[print 索引](../print/README.md)。

## 复制前检查

1. `print`/`callfunc` 名称在目标分派器中已实现，参数值在支持范围内。
2. `Self`、`Sender` 与事件触发路径一致。
3. 对象名、物品名、地图名和脚本编号能与目标 `Init`、`Setting` 和 `Script.SDB` 对应。
4. 配套 `Help`、`NpcSetting`、奖池及任务数据完整，奖励内容符合目标版本规则。
5. 按[脚本绑定与调试](../help/Script.md)完成加载和实际交互验证，再用于运行环境。

引用本目录实例时标注“云端千年神武奇章线上优化版脚本”，避免将运营定制写成官方通用规则。
