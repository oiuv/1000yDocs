# 炎黄新章游戏资料索引

本目录收录 123 份游戏资料，统一使用 Markdown、UTF-8（无 BOM）编码和 LF 换行，按主题整理标题、列表和表格。

资料原则上保留原文措辞、数值和顺序；原有空白字段不补填，表格中的空白不代表数值为零。已核实的资料错误可作勘误，并在对应页面注明依据及适用范围；不将运营版本的主动优化当作资料错误改写。

NPC 简介页的坐标按炎黄配置投放点核对，区分地图与同名 NPC；新手村页列出本地图实际投放记录。坐标不代表 NPC 活动后的固定站位。

这些资料用于说明玩家可见规则；涉及服务端字段、协议或实际执行逻辑时，仍需与 Pascal 源码及 `tgs1000/bin` 配置交叉核对。

官网补充资料注明原文链接及查阅日期，采用摘要与配置核对，不整篇转载。玩法资料只补充与本项目对应的通用基础内容，不收录台服独立活动、跨服玩法、排行榜、运营规则或客户端下载。世界背景与实际玩法分开描述，不以背景叙述证明功能已实现。

装备资料单独完整保存官网装备栏目的 16 篇、294 条记录，包括当前未配置的装备；官网数值与当前配置分开记录，不据此引入该栏目的地图或活动。各页属性、价格、品级及取得条件以官网为归档来源，数值差异及名称对应见[官网装备资料对照](<新手入门/【装备】简介/官网装备资料对照.md>)。
