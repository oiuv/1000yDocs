# 枪法介绍

枪法是近身攻击武功的一类。本页整理普通枪法、对应上层枪法及阅读入口。

## 普通与上层枪法

| 普通枪法 | 对应上层枪法 |
| --- | --- |
| 无名枪术 | 不羁浪人枪法 |
| 火龙升天术 | 卧龙式 |
| 飞月枪法 | 潜龙大飞式 |
| 达摩枪法 | 雷电枪法 |
| 打狗棒法 | 五虎风魔棍 |
| 点枪术 | 玉女枪法 |
| 杨家枪法 | 岳家枪法 |

表中的对应关系表示武功系列，不表示修炼满后会自动获得另一门武功。学习、使用和修炼是不同操作，应按秘籍说明和游戏提示进行。

## 绝世枪法

绝世枪法包括凤凰雷电戟、昭巫枪法、乌龙索命枪。它们不在上表的普通／上层分类中，属性资料见[绝世武功介绍（枪法）](<绝世武功介绍（枪法）.md>)，晋级流程见[四大神功与绝世武功进阶](<四大神功与绝世武功进阶.md>)。

## 属性怎么看

- 攻击速度、恢复、闪躲、命中、姿势维持与四部位的攻防属性应分别阅读，不能仅看一项伤害判断整套武功。
- 资料中的武功属性不等于角色最终面板；修炼程度、所用装备及其它生效状态也需要区分。
