# 四大神功与绝世武功进阶

四大神功属于绝世护体武功，与绝世攻击武功采用不同的晋级流程。这里的“一、二、三级”是武功层级，不是装备锻造段数，也不是角色境界。

晋级前须将对应层级修炼到 `99.99`。提交升级或参加考核时，还须启用要升级的武功；仅持有满级武功不等于当前正在使用它。

## 四大神功

与老侠客交谈，在任务菜单中申请相应层级，再收集材料并提交。

| 目标 | 申请条件 | 申请费用 | 提交材料 |
| --- | --- | --- | --- |
| 一级升二级 | 至少有一门一级神功修炼满，未持有其它升级任务物品，物品栏有空位 | 60 金元 | 侠客任务卷轴、火王牌、霸王牌、妖狐牌，各 1 个 |
| 二级升三级 | 至少有一门二级神功修炼满，未持有其它升级任务物品，物品栏有空位 | 80 金元 | 仙人卷轴、术士牌、公子牌、守护牌，各 1 个 |

申请时支付费用并领取卷轴；提交时检查正在使用的对应层级满级神功，升级并收取卷轴与三种牌。不是收集完材料后才首次缴费。

### 任务牌对应目标

| 任务牌 | 任务目标 |
| --- | --- |
| 火王牌 | 火王（变身后） |
| 霸王牌 | 石大王 |
| 妖狐牌 | 九尾狐（变身后） |
| 术士牌 | 魔道士 |
| 公子牌 | 太极公子 |
| 守护牌 | 雨中客 |

请保留任务卷轴，并按任务指引寻找对应目标；同名怪物不一定都掉落任务牌，也不是每次击杀都能获得。

## 绝世攻击武功

按武器类别寻找对应 NPC，选择二级或三级考核。

| 武器类别 | 申请 NPC |
| --- | --- |
| 拳法 | 捕盗大将 |
| 剑法 | 黑捕校 |
| 刀法 | 白捕校 |
| 槌法 | 牛俊 |
| 枪法 | 梅花夫人 |

基本流程：

1. 启用对应类别、对应层级且修炼到 `99.99` 的绝世攻击武功。
2. 关闭境界，按 NPC 提示卸下带属性装备并停用受限武功。
3. 准备二级考核所需的 60 金元，或三级考核所需的 80 金元。
4. 等待考场空闲并通过入场检查；费用在进入考场前收取。
5. 在专用考场完成挑战。考场不允许用药，不能以缴费或进入考场代替完成考核；成功后武功晋级。

各类属性资料见本目录的绝世拳、剑、刀、槌、枪法页面。本页不涉及招式武功消耗真气的升级操作，不能将这套 NPC 考核流程套用到招式上。
