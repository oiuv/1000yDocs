# 【炎黄新章】介绍——绿林峡谷怪物

## 绿林峡谷怪物

下表列出云端千年绿林峡谷常见的怪物及部分战利品。

| 怪物 | 部分战利品 |
| --- | --- |
| 豺狗 | 骨头一、血石 |
| 黄马 | 木皮、骨头一、血石 |
| 鹿 | 鹿角一、鹿茸一、天桃、血石 |
| 活虎 | 老虎指甲一、白龙斧、黄龙斧 |
| 龇牙熊 | 熊皮、生药 |
| 双角兽 | 犀牛皮一、犀牛角一、血石 |
| 野狼族 | 水石、墨铁刀、血石 |
| 火石女 | 钱币、生药 |
| 抓狂犀牛王 | 抓狂犀牛王的角、男女黄龙弓服 |

人形鬼、蹦鬼、媚鬼和赤魔可在万毒门找到。寻找职业材料可参阅[云端千年](<../../云端千年.md#职业材料来源>)，犀牛角的用途见[绿林峡谷任务](<【炎黄新章】介绍——绿林峡谷任务.md>)。
