# 【门派】简介 门派申请条件

## 门派申请条件

为了规范《千年》游戏中的门派，引入竞争机制，使得《千年》游戏更具有娱乐性和挑战性；《千年》游戏管理小组现颁布《千年》门派管理规定，希望玩家可以遵守此规定。

## 一、门派的成立

- **说明：** 达到解脱境或以上，当前未加入门派，且不是其它门派的门主或副门主，方可申请建立门派。

向捕盗大将购买对应门派石，并选择尚未被占领的建派位置。

## 二、门石放置地点限制

十大门派使用长城以南的固定建派区域，各种门石对应不同位置。具体见[门派石坐标](<【门派】门派石坐标.md>)。

表中的“创建落点”用于拖放门石；“建派后门石位置”用于建派后的门派管理。人物走到创建落点旁边，将门石拖到指定空地，避开人物和物件。区域外拖放可能没有提示。

## 三、如何成立门派

1. 向捕盗大将购买对应门派石。
2. 前往该门石对应的创建落点旁边，将门石从物品栏拖到指定空地。
3. 在弹出的输入框中填写门派名称，确认后成为门主。
4. 走到建派后的门石旁，输入 `@同意加入门派`，再用普通聊天发送 `加入成员自己的角色全名`。例如角色叫“张三”，就发送 `加入成员张三`，这句不加 `@`。
5. 看到“加入了……”后，自己的入派登记完成，即可招收成员并使用门派仓库。

## 四、门派的存在条件

门派石耐久度大于0

## 五、门派名称命名规定

1. 门派名称限制为6个字以内
2. 原则上门派名称可以任意命名
3. 门派名称不得含有特殊字符，只能为汉字、英文字母或数字及其组合，不符合标准将予以删除
4. 门派名称不能命名为有侮辱他人或者带政治色彩的名称，一经发现，将在不通知的情况下立即予以删除。

## 六、成立门派的好处

1. 在网络的世界中成立门派，实现你驰骋武林的梦想
2. 门派弟子间可以说悄悄话，可用悄悄话向你门派的同仁要求帮忙
3. 当同一门派的人登录时，将会在同门派成员的讯息视窗中显示讯息
4. 可以设立门派卒兵，用来保护门派石免於受攻击

## 七、门主的申请条件

只有解脱镜以上玩家方可以建立门派

## 八、其它

本规则的修改/解释/执行权归属千年小组所有。
