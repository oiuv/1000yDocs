# 【门派】门派石坐标

## 十大门派石坐标

十处建派位置均在**长城以南**。人物走到创建落点旁边，将对应门石从物品栏拖到该落点的空地，随后输入门派名称。

| 门派石 | 创建落点示例（X，Y） | 建派后门石位置（X，Y） |
| --- | --- | --- |
| 人龙石 | 529，679 | 529，688 |
| 巨象石 | 662，246 | 663，254 |
| 金鸡石 | 653，757 | 653，766 |
| 花窟石 | 821，626 | 823，635 |
| 河马石 | 700，519 | 701，525 |
| 玉犬石 | 255，222 | 255，228 |
| 玉猿石 | 652，704 | 655，710 |
| 玉蟾石 | 383，622 | 381，630 |
| 血狮石 | 395，388 | 389，396 |
| 血陵石 | 570，312 | 570，319 |

创建时使用中间一列的落点；建派后前往最后一列的门石位置进行门派管理。落点应避开人物和物件，区域外拖放可能没有提示。

## 建派条件

- 境界达到**解脱境或以上**。
- 当前未加入门派，也不是其它门派的门主或副门主。
- 持有对应门石，且该建派位置尚未被占领。

门石可向捕盗大将购买。详细操作见[门派申请条件](<【门派】简介 门派申请条件.md>)。

## 门主加入成员名单

建派并命名后，门主还需在自己的门石旁完成一次入派登记：

1. 输入 `@同意加入门派`。
2. 用普通聊天发送 `加入成员自己的角色全名`。例如角色叫“张三”，就发送 `加入成员张三`，这句不加 `@`。
3. 看到“加入了……”后，入派登记完成，可前往交易村药材商使用门派仓库。

如果建派后药材商提示“你还没有加入门派”，请先完成上述登记。更多操作见[门派指令](<【门派】简介 门派指令.md>)。
