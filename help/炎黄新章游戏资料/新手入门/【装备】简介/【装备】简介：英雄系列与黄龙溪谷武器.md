# 【装备】简介：英雄系列与黄龙溪谷武器

本页介绍炎黄新章的英雄防具、套装效果、铠甲制作材料及黄龙溪谷武器。

## 属性读法

- 表中数值为未加工装备的基础值，不含加工、武功、境界、药效及套装加成。
- 攻击、防御四元组依次为 **身体／头部／手部／腿部**。
- 攻速、恢复沿用装备说明中的正数标法，表示相应间隔的改善值，不是“每秒攻击次数”。
- 下列装备均可加工至四段，不表示获得时就是四段。

## 英雄铠甲制作

制造英雄铠甲须将裁缝职业提升至神工，材料如下：

| 成品 | 材料 |
| --- | --- |
| 男子英雄铠甲 | 男子黄龙弓服 ×1、沙焰鬼角 ×1、蟒骨 ×2、金元 ×100 |
| 女子英雄铠甲 | 女子黄龙弓服 ×1、沙焰鬼角 ×2、蟒骨 ×1、金元 ×100 |

四种材料各占一个技术窗材料槽。制造可能失败，失败会消耗投入材料，请提前准备。

沙焰鬼角、蟒骨分别为沙焰鬼、大蟒的掉落材料，寻找材料时请留意游戏内开放区域。
