# 【物品】简介：狐狸洞

本页介绍狐狸洞探索与兑换所需的物品。

| 物品 | 来源或用途 |
| --- | --- |
| 火石 | 火狐狸掉落材料；用于修炼洞火把 |
| 狐狸指甲、狐狸裘、狐狸尾巴 | 狐狸相关掉落材料；不要将普通狐狸尾巴当作妖华尾巴 |
| 潜行术 | 狐狸洞的死狼女掉落；交给阴阳师换取透视符，不是一本可直接学会的隐身武功 |
| 透视符 | 阴阳师以 1 本潜行术兑换 1 张，需留出物品栏空间 |
| 骨钥匙 | 风兄或牛美的制作时需要 2 个骨头；是否需要钥匙请看洞口提示 |
| 仙豆 | 补给品；将 5 个交给妖华可换妖华尾巴 |
| 妖华尾巴 | 与 99 朵白玫瑰一起交给九尾狐酒母兑换狐狸内丹 |
| 红玫瑰 | 狐狸洞的死狼女掉落 |
| 玫瑰脱色药 | 修炼洞的死狼女掉落 |
| 白玫瑰 | 九尾狐酒母兑换狐狸内丹所需的材料 |
| 狐狸内丹 | 交给妖华随机兑换一件装备 |

## 白玫瑰取得方式的限制

当前不能通过把玫瑰脱色药拖到地面红玫瑰上获得白玫瑰。不要按旧攻略反复尝试这一操作；白玫瑰的其他取得方式需以游戏内说明为准。

持有相应材料后，可按下列条件与妖华兑换；狐狸内丹还需要向九尾狐酒母提交妖华尾巴和 99 朵白玫瑰。

## 妖华兑换

- 仙豆 ×5：换取 妖华尾巴 ×1。
- 狐狸内丹 ×1：随机换取一件装备；不是一次取得全部装备。

可能获得的装备包括男女妖华袍、男女利齿靴，以及驱魔烈火弓、炎帝火灵斧、狼牙戟、月光刀、龙光剑、四季甲胄、狐狸手套。装备资料见[狐狸洞装备](<../【装备】简介/【装备】简介：狐狸洞.md>)。
