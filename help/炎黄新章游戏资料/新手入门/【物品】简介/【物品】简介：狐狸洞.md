# 【物品】简介：狐狸洞

本页整理狐狸洞探索与兑换涉及的通用物品。括号或代码中的名称是配置主键，不一定与物品栏显示文字完全相同。

| 物品 | 已核对的来源或用途 |
| --- | --- |
| 火石 | 火狐狸掉落材料；用于修炼洞火把 |
| 狐狸指甲、狐狸裘、狐狸尾巴 | 狐狸相关掉落材料；不要将普通狐狸尾巴当作妖华尾巴 |
| 潜行术 | 狐狸洞的死狼女掉落；交给阴阳师换取透视符，不是一本可直接学会的隐身武功 |
| 透视符 | 阴阳师以 1 本潜行术兑换 1 张，需留出物品栏空间 |
| 骨钥匙 | 风兄或牛美的制作选项检查并消耗 2 个骨头；存在该道具不表示所有洞口都要求它 |
| 仙豆 | 补给品，内部名 `仙豆一`；将 5 个交给妖华可换妖华尾巴 |
| 妖华尾巴 | 与 99 朵白玫瑰一起交给九尾狐酒母兑换狐狸内丹 |
| 红玫瑰 | 内部名 `红玫瑰一`，狐狸洞的 `死狼女虚像` 掉落 |
| 玫瑰脱色药 | 修炼洞的 `死狼女实像` 掉落；物品类型为 `ITEM_KIND_CHANGER` |
| 白玫瑰 | 内部名 `白玫瑰一`；九尾狐酒母兑换时检查的材料 |
| 狐狸内丹 | 内部名 `狐狸内丹三`；交给妖华兑换其奖励池中的装备 |

## 白玫瑰取得方式的限制

物品表保留红玫瑰、玫瑰脱色药与白玫瑰的关联，但当前 `TItemObject.FieldProc` 中地面物品转换分支已被注释。不能指导玩家把药拖到地面红玫瑰上并承诺可以脱色成功，也不能仅凭配方字段断言有可用的制作入口。

兑换材料已有独立来源时，酒母和妖华的兑换仍须按各自条件检查。这里不将材料表中的关系写成已经验证完整的任务闭环。类型限制见[物品类型说明](../../../constants/ITEM_KIND.md)。

## 妖华兑换

- `仙豆一 × 5`：换取 `妖华尾巴 × 1`。
- `狐狸内丹三 × 1`：从配置奖励池中随机取得装备；不是一次取得全部装备。

奖励池包括男女妖华袍、男女利齿靴，以及驱魔烈火弓、炎帝火灵斧、狼牙戟、月光刀、龙光剑、四季甲胄、狐狸手套。装备资料见[狐狸洞装备](<../【装备】简介/【装备】简介：狐狸洞.md>)。
