# 狐狸洞攻略

狐狸洞任务以收集材料、与妖华兑换装备为主。进入条件和路线见[狐狸洞介绍](<../版本介绍/狐狸洞介绍.md>)，材料用途见[狐狸洞物品](<../【物品】简介/【物品】简介：狐狸洞.md>)。

**注意：当前不能使用玫瑰脱色药把红玫瑰变成白玫瑰。** 白玫瑰的其他取得方式需以游戏内说明为准，不要按旧攻略反复尝试脱色。

## 寻找目标

狐狸洞与修炼洞的两种目标都叫“死狼女”，请按区域辨认，不要只看旧攻略中的“实像”“虚像”称呼。

| 目标 | 所在区域与出现方式 | 相关材料或用途 |
| --- | --- | --- |
| 火狐狸 | 狐狸洞 | 掉落火石 |
| 死狼女 | 狐狸洞 | 掉落红玫瑰、潜行术 |
| 死狼女 | 修炼洞，使用火石点亮两盏火把 | 掉落玫瑰脱色药 |
| 妖华 | 修炼洞，使用火石点亮全部四盏火把 | 接受仙豆或狐狸内丹兑换物品 |

## 材料与兑换

| 物品 | 取得方式 |
| --- | --- |
| 火石 | 击杀火狐狸 |
| 骨钥匙 | 找风兄或牛美，消耗 2 个骨头制作；是否需要钥匙请看洞口提示 |
| 潜行术 | 击杀狐狸洞的死狼女 |
| 透视符 | 用 1 本潜行术向阴阳师兑换 |
| 玫瑰脱色药 | 击杀修炼洞的死狼女 |
| 红玫瑰 | 击杀狐狸洞的死狼女 |
| 妖华尾巴 | 向妖华交付 5 个仙豆 |
| 白玫瑰 | 当前不能用玫瑰脱色药制作，其他来源以游戏内说明为准 |
| 狐狸内丹 | 向九尾狐酒母交付 99 朵白玫瑰和 1 个妖华尾巴 |
| 狐狸洞装备 | 向妖华交付 1 个狐狸内丹，随机换取一件装备 |

## 注意事项

1. 与妖华交换时，将材料拖到她身上，不是在聊天栏输入文字命令。
2. 每次交付 5 个仙豆可换 1 个妖华尾巴；每次交付 1 个狐狸内丹可随机换 1 件装备。
3. 提前留出物品栏空间，留意火把熄灭与目标消失。
