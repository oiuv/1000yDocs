# 【怪物】简介（狐狸洞）

下表列出狐狸洞与修炼洞的主要目标及相关材料，不是完整掉落清单，也不保证每次击杀都取得物品。

| 名称 | 所在区域或来源 | 相关材料 |
| --- | --- | --- |
| 火狐狸 | 狐狸洞 | 火石、狐狸指甲、肉块 |
| 白狐狸 | 狐狸洞 | 狐狸裘、狐狸尾巴、肉块 |
| 死狼女 | 狐狸洞，常见于 `(136, 45)` | 红玫瑰、潜行术 |
| 死狼女 | 修炼洞点亮两盏火后出现 | 玫瑰脱色药、金元 |
| 妖华 | 修炼洞点亮四盏火后召出 | 接受仙豆、狐狸内丹进行兑换 |

## 如何辨认

狐狸洞和修炼洞的目标都叫“死狼女”，但掉落材料不同，请按所在区域和出现条件辨认。

向妖华兑换物品，需要把材料交给她，不是击杀后拾取奖励。

怪物会移动，火把召出的目标也不一定一直停在出现的位置。
