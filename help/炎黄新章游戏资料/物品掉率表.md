# 物品掉率表

本表按物品汇总云端千年·炎黄新章的普通掉落和散落奖励，核对日期为 2026-11-25。任务条件下的击杀奖励，以及商店、制造、采集和活动奖励，各按对应玩法查看。

## 掉落方式

- **普通掉落**按怪物和物品累计判定。一个计数周期内随机命中一次，同一类怪物的掉落计数由玩家共用，个人连续击杀的出货间隔会有波动。命中时发放或掉出标注的数量。
- **散落奖励**在每次有效击杀时独立判定。触发后按整组投放。表中的「1×15 份」表示散落 15 份，每份 1 个。同一个物品若有两种掉落方式，两种都有机会出现。

同一种怪物即使在多个场景出现，也按同一掉落来源列出。括号用来区分掉落不同的同名怪，或说明怪物的触发方式。标注「出现场景待核」的条目已有掉落配置，出现地点或触发方式待确认。白狐狸的掉落按变身后的形态列出。

## 掉率档位

档位比较的是**触发频率**。普通档位对应单项掉落，散落档位对应整组触发。每次掉出的数量和散落的份数也影响最终能获得多少材料。

| 档位 | 长期平均触发频率 |
| --- | --- |
| 必掉 | 每次有效击杀触发 |
| 很高 | 约每 2～5 次触发一次 |
| 高 | 约每 6～20 次触发一次 |
| 中 | 约每 21～100 次触发一次 |
| 低 | 约每 101～500 次触发一次 |
| 很低 | 约每 501～1000 次触发一次 |
| 稀有 | 约每 1001～5000 次触发一次 |
| 罕见 | 约每 5001 次或更多触发一次 |
