# 采集技能指南

角色可以采药、挖铁矿、采水石和各类原石。采集与铸造、裁缝、工匠、炼丹分别成长，熟练度可在技术窗查看。

## 开通与采集操作

1. 想提升采集熟练度，可到长城以南 **（226，902）** 找聚贤庄庄主，选择「申请采集技能」。本服申请费为 **10 万钱币**。每个角色只需申请一次，无需加入门派或先学制造职业。进庄仍须遵守[聚贤庄入场规则](<云端千年.md#聚贤庄领土战>)。
2. 将十字镐装备到武器栏。铁匠出售青铜、钢铁和象牙十字镐。长城以南铁匠的任务奖励有机会获得高级象牙十字镐。
3. 选中采集点，靠近后挥镐。连续挥镐会累积进度，采到的材料直接进入背包。切换采集点会重新累积进度。同一采集点的储量由在场玩家共用，采完后等待刷新。

## 未开通采集技能

装备十字镐即可采初级材料。未开通时始终按初级工 **0.00 熟练度**结算，每次只抽取一次，采集熟练度也停在 **0.00**。换镐会影响材料产出，材料的等级要求照常生效。

如果长期只想采葛根、生铁或基础原石，可以直接用青铜十字镐，省下开通费用。开通后，熟练度在初级工阶段提高时，采基础材料会更稳定。升到更高称号后，进阶材料也会占掉一部分产出。

[乌矿石](#乌矿石)也可按初级工权限采集。购买、交易或从地上拾取的材料均不提供采集经验。

## 采集称号与材料

六档称号的熟练度范围和可采材料见[采集技能介绍](<新手入门/炎黄新章/【炎黄新章】介绍——采集技能介绍.md#采集技能等级>)。升到所需称号后，仍需到对应地点采集。

## 等级不足时哪些点会空采

**初级工在聚贤庄那类能出聚仙草、天麻草、千年地黄的药山，每次结算都会空采。** 这类药山的最低产物是聚仙草，需要达到**技能工（50.00）**。换更好的十字镐也得先满足这道等级要求。

聚贤庄还有一种能出葛根、天然参的药山，初级工可以在那里采葛根。庄内两类都显示为「药草」，刚开通技能时到长城以南野外药山起步更稳妥，野外两类药山都能采到葛根。

采集点若同时有基础和进阶材料，等级较低时仍有机会采到基础材料，也可能空采。例如初级工可以在铁矿二层采生铁，千年衔铁要到神工才有机会采得。

## 去哪里采

下表坐标为长城以南的入口或寻路参考。地下采石场、铁矿和矿山的入口均要求角色年满 **30 岁**。新手村、万毒门和绿林峡谷的职业材料主要通过怪物掉落和铁匠加工取得。

| 区域 | 入口或位置 | 主要产出 |
| --- | --- | --- |
| 长城以南野外药山 | 散布于野外 | 葛根、甘草、沙参等，部分药山可采天然参 |
| 聚贤庄 | 庄主 **（226，902）** | 药山可采聚仙草、天麻草、千年地黄等。水石点可采矿泉水石、千年刚玉、千年神石等 |
| 地下采石场 | **（762，268）** | 一层可采乌矿石，二层可采千年水石。两层均可采普通水石等材料 |
| 铁矿 | **（185，308）** | 两层都有生铁、钢铁、墨铁、玄铁。二层还能采熔岩铁和千年衔铁 |
| 矿山 | **（625，391）** | 一、六层采金属原石，二、五层采岩石原石，三、四层采宝石原石。四、五、六层分别可采千年水晶原石、千年金刚石原石、千年纯金原石 |

## 乌矿石

乌矿石是开启**地下采石场二层**入口的特殊矿物。地下采石场一层和聚贤庄部分水石点可以采到，未开通采集技能的角色也能采集。乌矿石本身没有采集经验。

### 选镐与熟练度

专采乌矿石时，优先使用**青铜十字镐**。在同一采集点、相同熟练度下，青铜十字镐的乌矿石平均产出高于其他三把镐。

按现行采集结算，从 **0.00** 起提升熟练度，乌矿石产出会明显增加。熟练度达到 **30.00** 后，各阶段的差距相对较小。在同一水石点使用青铜十字镐，**初级工 40.00～49.99** 的平均产出最高，约为 **0.00 熟练度的 5 倍**。升到技能工后，会采到优先产出的碳酸水石，乌矿石的产出会先下降。练到神工时，乌矿石平均产出约为 **0.00 熟练度的 4.2 倍**。

### 开启地下采石场二层

在地下采石场一层，靠近 **（169，72）** 的火柱，将乌矿石**逐个放入**。机关累计收齐 **8 个**后，仍在附近、放过乌矿石的玩家会被传送到二层。

## 采集结算与产物顺序

### 怎样抽取产物

1. **按熟练度决定抽取次数。** 挥镐累积到一次结算后，0.00 熟练度抽 1 次，每满 **10.00** 多抽 1 次。例如 40.00 抽 5 次，50.00 抽 6 次，90.00 起抽 10 次。未开通采集技能按 0.00 结算。
2. **抽取候选材料。** 每次抽取各自独立，抽到各材料的机会取决于采集点的种类和使用的十字镐。
3. **筛选并发放。** 等级不足的候选作废，抽取次数照常计入。系统从剩下的候选中，按下面的顺序发放最靠前的一份。若所有候选都作废，本次空采，也会消耗一次采集点的储量。

### 各采集点的产物优先顺序

表中**越靠左越优先**，同一采集点的顺序适用于四种十字镐。

| 采集点 | 产物优先顺序 |
| --- | --- |
| 地下采石场一层 | 吸着水石 → 矿泉水石 → 温泉水石 → 冷却水石 → 碳酸水石 → 乌矿石 → 普通水石 |
| 地下采石场二层 | 千年水石 → 爆裂水石 → 吸着水石 → 矿泉水石 → 温泉水石 → 冷却水石 → 碳酸水石 → 普通水石 |
| 聚贤庄水石点（产千年刚玉） | 千年刚玉 → 矿泉水石 → 温泉水石 → 冷却水石 → 碳酸水石 → 乌矿石 → 普通水石 |
| 聚贤庄水石点（产千年神石） | 千年神石 → 爆裂水石 → 吸着水石 → 矿泉水石 → 温泉水石 → 冷却水石 → 碳酸水石 → 普通水石 |
| 产天然参的药山（野外和聚贤庄均有） | 天然参 → 地种参 → 何首乌 → 沙参 → 甘草 → 葛根 |
| 野外另一类药山 | 地种参 → 何首乌 → 沙参 → 甘草 → 葛根 |
| 聚贤庄药山（产聚仙草） | 千年地黄 → 玄参 → 血红花 → 天麻草 → 聚仙草 |
| 铁矿一层 | 玄铁 → 墨铁 → 钢铁 → 生铁 |
| 铁矿二层 | 千年衔铁 → 熔岩铁 → 玄铁 → 墨铁 → 钢铁 → 生铁 |
| 矿山一层 | 白金原石 → 黄金原石 → 砂金原石 → 黄铜原石 → 青铜原石 |
| 矿山二层 | 耀阳原石 → 玄石原石 → 月石原石 → 黑石原石 → 硅石原石 |
| 矿山三层 | 黑珍珠原石 → 白玉原石 → 黄玉原石 → 绿玉原石 → 青玉原石 |
| 矿山四层 | 千年水晶原石 → 黑珍珠原石 → 白玉原石 → 黄玉原石 → 绿玉原石 → 青玉原石 |
| 矿山五层 | 千年金刚石原石 → 耀阳原石 → 玄石原石 → 月石原石 → 黑石原石 → 硅石原石 |
| 矿山六层 | 千年纯金原石 → 白金原石 → 黄金原石 → 砂金原石 → 黄铜原石 → 青铜原石 |

例如在地下采石场一层，同一次结算抽到**碳酸水石、乌矿石和普通水石**。初级工会筛掉碳酸水石，拿到乌矿石。技能工达到碳酸水石的等级要求，会拿到碳酸水石。

## 神工采集选镐指南

四把镐的挥镐速度相同。以下倍率按现行产出结算，比较神工在同一种采集点完成相同次数采集时，目标材料的平均产出。详见[本服采集修复与产出调整](<云端千年.md#本服采集修复与产出调整>)。

### 青铜十字镐

适合专采基础材料，例如生铁、葛根、乌矿石和基础原石。下表列出青铜十字镐的产出倍率，以高级象牙十字镐的平均产出为 **1 倍**。

| 专采目标 | 采集地点 | 产出倍率 |
| --- | --- | --- |
| 生铁 | 铁矿二层 | 约 **1.5 倍** |
| 乌矿石 | 地下采石场一层 | 约 **2.9 倍** |
| 葛根 | 长城以南野外药山 | 约 **2.8～5.9 倍**，随药山种类而异 |
| 青铜原石、硅石原石、青玉原石 | 矿山一、二、三层，各采对应材料 | 约 **7.2 倍** |

### 钢铁十字镐

适合兼收基础和进阶材料。在长城以南能出天然参的那类药山，如果**葛根和沙参都要**，钢铁十字镐的两种材料合计产出在四把镐中略高。在铁矿二层，钢铁十字镐采到的玄铁比青铜十字镐多，采到的生铁比高级象牙十字镐多。

### 象牙十字镐

采**天然参、熔岩铁**，或矿山前三层各自对应的**白金原石、耀阳原石、黑珍珠原石**，象牙十字镐和高级象牙十字镐的平均产出相同。在长城以南不出天然参的那类野外药山，如果**葛根和沙参都要**，象牙十字镐的合计产出最高。

### 高级象牙十字镐

适合专采多数进阶材料，例如玄铁、沙参、何首乌和千年地黄。在铁矿二层采**玄铁**，高级象牙十字镐的平均产出约为青铜十字镐的 **2.1 倍**。在聚贤庄药山采**千年地黄**，高级象牙十字镐的平均产出约为青铜十字镐的 **4.4 倍**。

### 按楼层和目标换镐

专采**墨铁**时，铁矿一层用青铜十字镐，二层用高级象牙十字镐。专采**千年刚玉、千年神石、千年衔铁、千年水石或三种千年原石**时，四把镐在同一采集点的机会相同，可以按想顺手采的材料选镐。
