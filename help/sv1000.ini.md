# sv1000.Ini

`sv1000.Ini` 是 TGS 进程连接、缓冲区和 UDP 日志目的地址配置。程序从工作目录读取该文件。随包模板 `sv1000.Ini.example` 与本地运行配置应分开核对；实际配置项覆盖源码默认值，缺失项使用默认值。运行文件不作为固定的公共配置基准，不能根据某份本地文件推断所有部署的节、键或取值。

## SERVER 与 DATABASE

| 键 | 源码默认值 | 行为 |
| --- | ---: | --- |
| `SERVER.GAMESTARTDATE` | 编译时游戏开始日期 | 用 `StrToDate` 解析并计算 `GameCurrentDate`；格式必须符合服务器系统区域设置 |
| `SERVER.BUFFERSIZES2S` | 1048576 | 服务器间发送缓冲区大小 |
| `SERVER.BUFFERSIZES2C` | 8192 | 接收/客户端相关缓冲区大小；示例文件配置为 32768 |
| `SERVER.WAITPLAYERTIME` | 10000 | 直接写入 `WAITPLAYERTICK`，并与 `mmAnsTick` 相加比较，不是由加载器按秒换算 |
| `DATABASE.COUNT` | 0 | 每次启动读取后加 1 并写回文件 |
| `DATABASE.DATE`、`DATABASE.HOUR` | 空、0 | 启动时读入 `IniDate`、`IniHour`；当前工程未找到后续消费代码 |

## TCP 目标

`DB_SERVER`、`BATTLE_SERVER`、`NOTICE_SERVER` 均读取 `IPADDRESS` 和 `PORT`，默认分别为 `127.0.0.1:3051`、`:3040`、`:3020`。当前 TGS 加载器不读取 `NOTICE_SERVER.LOCALPORT`。

## UDP 日志目标

| 节 | 默认端口 | 用途 |
| --- | ---: | --- |
| `UDP_ITEM` | 6001 | 物品日志 |
| `UDP_MOUSEEVENT` | 6001 | 鼠标事件；仓库示例改为 6010 |
| `UDP_MONITER` | 6000 | 监控日志；拼写必须保持 `MONITER`，仓库示例改为 6011 |
| `UDP_CONNECT` | 6022 | 连接日志 |
| `UDP_PAY` | 6000 | 付费日志 |
| `UDP_OBJECT` | 3003 | 对象日志 |
| `UDP_RELATION` | 3005 | 关系日志 |

每节都读取 `IPADDRESS`（默认 `127.0.0.1`）和 `PORT`。这些地址是 TGS 的 UDP 发送目标，对应日志服务应在该地址和端口监听。

## 校验依据

- 加载器：[SVMain.pas](TGS核心源码/SVMain.pas) 中的 `ReadInteger`、`ReadString` 默认参数。
- 等待时间使用点：[FGate.pas](TGS核心源码/FGate.pas)；缓冲区及连接相关使用点另见服务端工程的 `FSockets.pas`、`uConnect.pas`。
- 部署时分别核对随包模板与工作目录中的实际 `sv1000.Ini`；模板值不代表程序默认值或线上取值。
