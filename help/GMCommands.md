# GM 管理命令

本页按炎黄新章 Pascal 源码的实际分发和处理逻辑整理。聊天框中的 `@` 指令与脚本的 `print`、`callfunc` 是不同入口；没有单独的 `@管理` 总命令。

历史 CHM 仅作参考，不用于判定当前支持的指令。当前实现没有读取 `Command.ini` 来自定义 GM 命令的路径。

## 权限、输入与影响范围

- 服务器从程序根目录 `Sysop.SDB` 按角色名读取 `SysopScope`。主要 GM 分支要求 `SysopScope > 99`，即 100 也满足条件，不是必须大于 100。
- 角色初始化时，达到 100 的权限转为 101。`@解除躲闪`、`@设定躲闪` 在 100、101 间切换，影响战斗保护逻辑；它们不是修改装备躲闪属性，也不等于外观隐身。
- 参数通常用空格分隔，不支持通用的引号包裹多词参数。表中的方括号表示可选参数，不要输入方括号；问题、答案、公告等少数命令另取整段剩余文本。
- 命令的大小写处理并不统一。请使用表中写法，尤其是 `@scriptload`、`@swk`、`@lifedata`。许多中文命令经过 `Conv()`，如果部署替换了 `tgs1000.acs`，应核对对应映射；找不到映射时保留源码原字符串。
- 物品名、武功名、NPC 名等按各处理函数查找，通常使用配置内部名称，不应直接以显示名代替。`@移动` 使用地图标题，不是地图编号或地图文件名。
- 本页“全局”指当前 TGS 进程，不保证同步到另一个独立 TGS 进程。未带玩家参数的角色修改通常作用于操作者自己。
- 命令存在不等于已在线验收。下文明确标出的风险入口，不应当作可靠运营功能使用。

源码依据：[UUser.pas](TGS核心源码/UUser.pas) 的 `TUser.Initial`、`BreakStr`、`TUser.UserSay`、`BuildSayCommand`；[svClass.pas](TGS核心源码/svClass.pas) 的 `TSysopClass`。权限文件维护见 [运行时数据](RuntimeData.md#sysopsdb)，ACS 见 [程序根目录资源](RuntimeResources.md)。

## 移动、定位与召集

本节是管理员操作，不等同于玩家踩门、随机传送或投物多人传送。配置与脚本入口见 [地图传送机制总览](Teleportation.md)。

| 指令 | 实际作用与限制 |
| --- | --- |
| `@移动 地图标题 X Y` | 自己移动到对应地图坐标，先检查目标坐标是否可移动；不要依赖省略坐标自动寻找落点 |
| `@出兵 玩家名` | 自己移动到在线玩家所在位置，不是把玩家召来 |
| `@唤回 玩家名` | 将在线玩家移到自己所在位置 |
| `@团队移动 地图标题 X Y 团队编号` | 仅遍历当前视野内的玩家，移动 `GroupKey` 匹配者；不是全服搜集团队 |
| `@探查 玩家名` | GM 直接查询在线玩家的地图标题和坐标；此命令名来自 `game.ini` 的 `STRINGS/SERCHSKILL`，源码默认是 `@SERCHSKILL` |
| `@APPEARNPC NPC名` | 自己移动到当前地图内查找到的 NPC 位置 |
| `@APPEARMOP 怪物名` | 自己移动到当前地图内查找到的怪物位置 |
| `@APPEARDYN 动态对象名` | 自己移动到当前地图内查找到的动态对象位置 |
| `@CALLNPC NPC名` | 将当前地图内查找到的已有 NPC 移到附近可移动位置，不创建新 NPC |
| `@CALLMOP 怪物名` | 将当前地图内查找到的已有怪物移到附近可移动位置，不创建新怪物 |
| `@召唤怪兽 怪物名` | 让当前地图中已有的同名怪物向操作者坐标移动；跳过待删除或没有攻击技能的怪物，不创建新怪物 |

依据：[UUser.pas](TGS核心源码/UUser.pas) 的 `TUser.UserSay`；[uManager.pas](TGS核心源码/uManager.pas) 的 `GetManagerByTitle`。

## 物品、角色与任务

| 指令 | 实际作用与限制 |
| --- | --- |
| `@item 物品名 数量` | 创建物品到自己背包。GM 可选择物品表中的物品；非叠加物品强制为 1 个，仍需背包能容纳 |
| `@整理道具` | **删除自己背包中的全部物品，不是整理排序**；不以此代替普通背包整理 |
| `@修改武功 武功名 数值` | 修改自己已经拥有的武功。输入范围 100～9999，使用技能内部数值；不会凭空学习该武功 |
| `@武功删除 武功名` | 删除自己的武功。GM 跳过每日一次限制，但不跳过密码及对应删除分支的检查 |
| `@技能初始化` | 将自己的职业种类、职业等级设为无；不等于清空全部职业材料或全部经验数据 |
| `@技能设定 经验值` | 已有职业时，设置职业技能经验并重算等级，不是直接填写显示等级 |
| `@任务数据` | 显示自己的 `CompleteQuestNo`、`CurrentQuestNo`、`QuestStr`、`FirstQuestNo` |
| `@任务设定 完成任务号 当前任务号 任务字符串 首任务号` | 直接改写上述四项字段，不修改独立事件标记 |
| `@修改经验值 倍率` | 设置当前 TGS 的全局 `ExpMulti`，不是给自己增加经验 |
| `@修改浩然正气 倍率` | 设置当前 TGS 的全局 `VirtueMulti`，不是直接改自己的浩然正气 |
| `@设定隐身`、`@解除隐身` | 设置自己的外观隐藏状态，分别使用 `hs_0`、`hs_100` |
| `@设定躲闪`、`@解除躲闪` | 分别将自己的权限状态改为 101、100，改变相关战斗保护分支 |
| `@还生` | 向本地广播恢复消息：接收的玩家补满元气、活力、内外武功、头手脚生命和护盾，并重置死亡计时；不是只指定某一个玩家 |
| `@DIE` | 清零自己的活力、内外武功、头手脚生命 |
| `@EMPTY` | 清零自己的活力、内功、外功和武功 |

### 使用限制

- `@item` 并非完全 GM 专属：普通玩家只能创建 `SpecialKind=ITEM_SPKIND_GOLBANG` 的物品，且不走 GM 数量设置分支。中国版本只处理名称和数量；升级、附加属性、耐久参数仅在韩国版本条件分支中处理。详见 [Item.SDB 的指令说明](Init_item.sdb.md#关于item指令)。
- `@修改武功` 的 `HaveBestSpecialMagicArr` 分支将经验和技能值清零，不使用传入值；不能据一般武功行为推断所有绝世武功都适用。
- 两个倍率命令直接赋值，未校验倍率上限或正负，也不保存配置。只使用经确认的正整数倍率；重新启动后以程序初始化值为准。
- 清空背包、删除武功和重置职业会改变角色数据，不提供聊天命令撤销。

依据：[uUserSub.pas](TGS核心源码/uUserSub.pas) 的 `DeleteAllItem`、`EditHaveMagicByName`、`ClearJobData`、`SetJobTalent`；[UUser.pas](TGS核心源码/UUser.pas) 的 `TUser.UserSay` 和 `FM_REFILL` 接收分支。

## 公告与有奖答题

| 指令 | 实际作用 |
| --- | --- |
| `@呐喊 内容` | 向当前 TGS 的在线玩家发送中央消息 |
| `@问题 内容` | 设置题目，保留命令后的剩余文本 |
| `@答案 内容` | 设置答案，保留命令后的剩余文本 |
| `@奖品 物品名 数量` | 设置一种奖品及数量，不支持在此命令中列出多种物品 |
| `@问题确认` | 向操作者显示题目、答案、奖品和数量 |
| `@答题开始` | 开启答题，广播题目与奖品 |

设置奖品时只存储名称和数量，没有立即验证发奖能否成功。应先核对物品内部名称和正整数数量，再确认题目、答案后开启。源码没有对应的 `@答题结束` 管理分支；玩家作答使用普通命令 `@答`。

另有两个非 `@` 的相关入口：

| 输入 | 权限与作用 |
| --- | --- |
| `# 内容` | 首个词必须为单独的 `#`；权限大于 50 且整条文本长度大于 4 时，发送带 `<SYSTEM>:` 前缀的公告 |
| `/who` | 实际命令字来自 `game.ini` 的 `STRINGS/WHO`。中国版本中权限至少 99 才查询在线人数；门派信息分支另行判断，不是整条命令只供 GM 使用 |

依据：[UUser.pas](TGS核心源码/UUser.pas) 的 `TUser.UserSay`；[svClass.pas](TGS核心源码/svClass.pas) 的 `TQuizSystem`。配置键见 [game.ini](game.ini.md)。

## 断线与囚禁

| 指令 | 实际作用与限制 |
| --- | --- |
| `@BAN 玩家名 [说明]` | 请求在线角色断线，发送固定的管理断线提示及可选说明；不是永久封号 |
| `@BANEX 玩家名 [说明]` | 同样请求断线，但不发送固定的“人物已被管理者强制断线”提示；有说明仍会发送 |
| `@囚禁 玩家名 类型 原因` | 新增囚禁记录；若角色在线，提示其重新连接并断线 |
| `@释放 玩家名` | 删除已有囚禁记录；该命令本身不直接传送在线角色 |
| `@修改囚禁资料 玩家名 类型 [原因]` | 重设总刑期和类型，已服刑时间清零；提供原因时覆盖旧原因 |
| `@追加囚禁资料 玩家名 类型 [原因]` | 增加总刑期，保留已服刑时间，并将类型改成此次参数；有跨重启丢失追加量的问题 |
| `@设定囚禁时间 玩家名 分钟数 [原因]` | 直接设置总刑期，保留已服刑时间，并把类型设为 `C`；有跨重启失效的问题 |
| `@囚禁情报 [玩家名]` | 当前先命中普通命令表，只查询自己，忽略玩家名；后面的 GM 查询他人分支不可达 |

“类型”不是直接填写分钟数：

| 类型 | 实际换算 |
| --- | --- |
| `A1`、`A2`、`A3`…… | 3 天、6 天、12 天……，从 3 天开始按次数翻倍 |
| `B<n>` | n 天 |
| `M<n>` | n 天，上限 3 天；不是 n 分钟 |

类型参数应使用合理的正整数，避免未经完整校验的零值、负值或过大值。

### 刑期保存限制

保存时写出 `PrisonTime`，但加载时根据 `PrisonType` 重新计算总刑期，不读取保存的 `PrisonTime`。因此：

- `@追加囚禁资料` 的累计结果不会按累计值恢复，而会变成最后一次保存类型对应的刑期。
- `@设定囚禁时间` 保存的类型为 `C`，换算器没有 `C` 分支，加载后得到 0。
- 这些是程序实现限制，不能把“写出了 SDB”理解为刑期已经可靠持久化。

依据：[svClass.pas](TGS核心源码/svClass.pas) 的 `TPrisonClass.GetPrisonTime`、`LoadFromFile`、`SaveToFile`、`AddUser`、`UpdateUser`、`PlusUser`、`EditUser`；维护规则见 [Prison.SDB](RuntimeData.md#prisonsdb)。

## 重载、福袋与物品流转开关

| 指令 | 实际作用与限制 |
| --- | --- |
| `@scriptload` | 调用 `ScriptManager.LoadFromFile`，读取 `Script/Script.SDB` |
| `@HELPFILERELOAD` | 调用 `HelpFiles.LoadHelpFiles` 重载帮助页面 |
| `@重载任务摘要` | 重载任务摘要表 |
| `@NPCSETTING NPC名` | 对当前地图中首个名称匹配的 NPC，重载已有交易、说话技能所用的 `NpcSetting/名称.txt` 和 `.sdb`；不是全服 NPC 或脚本重载 |
| `@REGENMAP` | 临时把当前地图刷新间隔设为 1 并调用地图更新，再恢复间隔；用于触发地图重置，不是通用的物品表重载 |
| `@储存保管窗` | 导出福袋快照到 `ITEMLOG/ITEMLOG.SDB`，不是导入或恢复主库 |
| `@锁定保管窗` | 切换全局 `ItemLog.Enabled`；每执行一次取反，不是始终执行“锁定” |
| `@MOVEITEMSTARTORBER`、`@MOVEITEMENDORBER` | 分别打开、关闭全局 `boMoveItem` |
| `@MOVEALLITEMSTARTORBER`、`@MOVEALLITEMENDORBER` | 分别打开、关闭全局 `boMoveAllItem` |

`boMoveItem` 影响丢弃、交换、部分福袋/门派仓库及地面操作；`boMoveAllItem` 还参与商店、摆摊及更多转移路径。二者不是覆盖所有物品操作的总闸门：背包内部换位、穿脱装备、技术材料等路径不全部检查它们；同时关闭两者后，只打开其中一个也不能恢复需要两个开关都开启的路径。

以上开关命令只修改进程内状态，不写入配置文件。福袋导出含敏感数据，详见 [ITEMLOG](ITEMLOG.md)。

依据：[UUser.pas](TGS核心源码/UUser.pas) 的 `TUser.UserSay`、物品拖放处理；[uNpc.pas](TGS核心源码/uNpc.pas) 的 `ReLoadFromNpcSetting`；[uManager.pas](TGS核心源码/uManager.pas) 的 `TManager.Update`。

## 门派与战场

| 指令 | 实际作用与限制 |
| --- | --- |
| `@CALLGUILD 门派名` | 将指定门派石移到操作者当前地图与坐标 |
| `@删除门派 门派名` | 将门派耐久设为 0 并执行门派清理、列表广播，属于破坏性操作 |
| `@设定聚贤庄门派 [门派名]` | 将已有门派设为占领门派；不带参数清除归属。设置会取消当前领土战、重置大旗并保存 `Init/Zhuang.sdb`；门派不存在时拒绝修改 |
| `@CREATEGUILD 门派名` | 优先走普通命令表，传入操作者姓名，要求匹配已有门派掌门及建石条件；不是 GM 无条件创建新门派的入口 |
| `@REGEN` | 重置当前战场及战况条相关状态 |
| `@BATTLESTART` | 将当前战场玩家设为自由行动，关闭进入，并发送开战消息 |
| `@BATTLEEND` | 将当前战场玩家设为冻结状态，关闭进入；不能据名字推断它还完成全部结算 |
| `@REMAINUSER 门派名` | 显示当前战场该门派剩余人数 |
| `@NAMELISTLOAD` | 调用名单重载并开放进入；当前加载路径不一致，不能认定名单已成功加载 |
| `@BATTLEMAPLOAD` | 重载 `Event/BattleMap.sdb` |
| `@BANALL X Y` | 将当前战场玩家移到地图编号 1 的指定坐标，不是全体封号；X、Y 为 0 时拒绝 |

从 `@REGEN` 到 `@BANALL` 这七条指令仅在 `MAP_TYPE_GUILDBATTLE` 或 `MAP_TYPE_SPORTBATTLE` 地图执行；不适用于任意普通地图。

### 当前实现限制

- `@NAMELISTLOAD` 的底层函数检查 `Event/NameList.SDB`，实际读取 `EtcSetting/NameList.SDB`；重载没有向命令返回成功标志，命令随后仍会开放进入。详见 [事件配置](Event.md#可选但未部署的表)。

依据：[UUser.pas](TGS核心源码/UUser.pas) 的 `TUser.UserSay`；[uGuild.pas](TGS核心源码/uGuild.pas) 的 `CreateStone`、`MoveStone`、`DeleteStone`；[svClass.pas](TGS核心源码/svClass.pas) 的 `TNameClass.ReLoadFromFile`。

### 位置、真气与武功调试

下列中文指令适用于支持 GM 命令汉化的 TGS，名称由代码直接识别，不依赖 ACS；均要求 `SysopScope > 99`。随文源码副本用于参考参数及处理逻辑。

| 指令 | 实际作用 |
| --- | --- |
| `@位置检查 X Y` | 检查坐标不可移动时对应的占用对象 ID/类别 |
| `@真气修改 数值` | 设置自身可分配真气点 `AddableStatePoint` |
| `@晋级信息` | 显示自身当前晋级信息 |
| `@绝世武功修改 武功名 技能值 阶段 攻击串 防御串` | 修改已有绝世武功数据。命令层允许阶段 0～3；攻击串、防御串各用 `/` 分隔五项，顺序为身体、头、手、脚、元气，每项按 0～99 解析并换算 |
| `@武功修改2 武功名 主值 子值` | 另一种武功经验设置入口，主值范围 1～99，子值范围 0～99 |
| `@附加属性编号` | 显示技术窗成品的 `AddType`，不是查询任意背包物品 |

| 指令 | 当前状态 |
| --- | --- |
| `@READ`、`@MOVE`、`@JANGSUNG` | 整段被注释，没有可执行命令分支；不能用 `@READ` 在线重载权限表或物品表 |
