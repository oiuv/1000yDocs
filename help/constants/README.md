# 游戏常量定义参考手册

> 源码位置: [deftype.pas](../deftype.pas)（3966 行）

本文档整理了千年游戏中所有关键常量定义，按功能分类组织。

英文常量保留源码拼写；中文采用客户端和随包游戏资料中的名称，遵循[术语对照表](../TERMINOLOGY.md)。物品显示名优先核对 `Item.sdb.ViewName`，不能仅凭 `Name` 或英文常量翻译。内部标记、保留定义与已实现的玩家功能分别说明。

## 快速查阅

### 物品系统

- **物品类型**: `ITEM_KIND_*` — 定义物品的功能和行为
- **物品属性**: `ITEM_ATTRIBUTE_*` — 火/水/冰/套装等属性
- **物品特殊类型**: `ITEM_SPKIND_*` — 灵符/饰品/卷轴等属性加工材料分类，以及其它功能标记

### 武功系统

- **客户端武功界面**: “武功”主菜单内含武功（普通武功）/基本/上层三个卡片；
  掌法和绝世武功是独立主菜单。`MAGICCLASS_*` 对应普通武功/上层武功/掌法/
  绝世武功，基本武功使用独立协议流
- **武功类型**: `MAGICTYPE_*` — 拳法/剑法/刀法/槌法/枪法/弓术/投法、步法、心法、护体等
- **武功派别**: `MAGIC_KIND_*` — 正邪两派的四大神功分类及特殊步法标记

### 职业系统

- **制造职业**: `JOB_KIND_*` — 铸造师/炼丹师/裁缝/工匠；采矿、冶炼相关内部定义另见职业文档
- **职业品级**: `JOB_GRADE_*` — 初级工→技能工→熟练工→达人→名人→神工

### 地图与对象

- **地图类型**: `MAP_TYPE_*` — 冰/火/初学/战斗等
- **传送门类型**: `GATE_KIND_*` — 普通/特殊时间/限制人数等
- **种族**: `RACE_*` — 人类/物品/怪物/NPC/动态对象
- **对象分类**: `CLASS_*` — 人类/怪物/NPC/物品/动态对象等

### UI 与通信

- **窗口类型**: `WINDOW_*` — 物品/装备/武功/交易等
- **消息类型**: `SM_*` (服务端) / `CM_*` (客户端) / `FM_*` (场景)
