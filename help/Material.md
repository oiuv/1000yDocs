# 技能材料

本页以炎黄新章 Pascal 源码、`gameserver-tgs1000/bin` 随包数据及炎黄原始游戏资料为当前版本依据。`docs/Script` 中的云端千年神武奇章线上优化版脚本只放在末尾作运营版本对照，不据此宣称原版神武或炎黄当前仍有相同兑换、活动或奖励。

## 技术窗放料与服务端校验

技术窗包含四个材料槽和一个加工物品/产物槽；放入材料不等于已经完成制造。制造仍需经过配方、职业、工具、数量等后续判断，配方见 [制造对照表](manufacture.md)。

- 普通拖入、数量确认和 `CM_SETMATERIAL` 批量放料都检查角色物品移动权限、背包锁、地图、当前窗口、死亡/摆摊状态及物品密码；并拒绝物品锁定或 `boNotSkill=true` 的物品。
- 数量确认会重新读取当前背包槽，再校验物品、锁和库存。不能只信任打开数量窗时的状态，也不能借另一类数量窗口提交放料。属于当前材料动作的确认无论成功、拒绝还是取消，均结束该数量窗口状态，玩家可重新发起操作；不会清除其它业务窗口。开窗后死亡时，合法的材料确认/取消也只做拒绝收尾，不转移物品。
- 批量放料要求技术窗五个槽均为空。报文有四组背包槽号和数量，原生客户端未用的组为 `(0,0)`；有材料的数量须在 `1..10000` 内，同一背包槽重复出现时按累计数量核对库存。
- 整批检查通过后才移动材料；任一组被拒绝时不应留下“前几组已移入”的部分结果。材料合并只限同名、颜色、加工等级及附加类型一致且可堆叠的物品，不占用加工物品槽。
- 从背包拖入加工物品槽时，只允许一件具有 `MaxUpgrade` 的可加工物品。该槽也由 `PutProductItem` 等方法接收制造产物，后者不是玩家拖入路径，不能把拖入限制套到所有产物；该槽不能当作额外材料格或绕过背包限制的储物格。

依据：[UUser.pas](TGS核心源码/UUser.pas) 的 `AllowMaterialMove/DragProcess/MessageProcess`；[uUserSub.pas](TGS核心源码/uUserSub.pas) 的 `PutOnMaterialProcess/PutOnMaterialCount/PutOnAutoMaterialProcess/AddMaterialItem`。物品字段含义见 [Item.SDB](Init_item.sdb.md#物品限制的实际边界)。

## 采集等级

以下物品来自炎黄原始资料《采集技能介绍》，并与当前 `MineObject.sdb`、`Item.sdb` 交叉核对：

- 初级工：葛根、生铁、普通水石、青铜原石、硅石原石、青玉原石。
- 技能工：甘草、聚仙草、钢铁、碳酸水石、黄铜原石、黑石原石、绿玉原石。
- 熟练工：沙参、天麻草、墨铁、冷却水石、温泉水石、砂金原石、月石原石、黄玉原石。
- 达人：何首乌、血红花、玄铁、矿泉水石、吸着水石、千年刚玉、黄金原石、玄石原石、白玉原石。
- 名人：地种参、玄参、熔岩铁、爆裂水石、白金原石、耀阳原石、黑珍珠原石。
- 神工：天然参、千年地黄、千年衔铁、千年水石、千年神石、千年纯金原石、千年金刚石原石、千年水晶原石。

## 当前炎黄资料可确认的用途与来源

这里仅列出能够由当前随包数据、脚本或炎黄原始资料直接确认的来源，不把“物品存在”推断成“可以通过某活动获取”。

| 材料 | 当前用途 | 当前可确认来源 |
|------|----------|----------------|
| 冰玉 | 制作百炼雨中客斗笠、道袍 | 王陵密室相关任务/怪物掉落；`比武上古雨中客.txt` 随机奖励冰玉或金刚石；`RandomEventItem2.sdb` |
| 金刚石 | 加工王陵系列装备 | 王陵资料所述产出；`比武上古雨中客.txt` 随机奖励；`RandomEventItem0.sdb`、`RandomEventItem2.sdb`；部分当前怪物掉落 |
| 千年刚玉 | 百炼狐狸系列材料 | 达人采集；`比武北霸王.txt` 和 `比武东天王.txt` 都可能随机奖励千年刚玉或千年神石 |
| 千年神石 | 百炼技能系列材料 | 神工采集资料；`比武北霸王.txt` 和 `比武东天王.txt` 都可能随机奖励千年刚玉或千年神石 |
| 千年衔铁 | 技能装备及百炼装备材料 | 神工采集；熔岩铁经当前 `铁匠.txt`/`SmeltItem.sdb` 提炼 |
| 千年水石 | 技能装备材料 | 神工采集；`RandomEventItem2.sdb` |
| 千年金刚石 | 花郎系列技能装备材料 | 采集千年金刚石原石后由当前铁匠提炼 |
| 千年水晶 | 技能装备材料 | 采集千年水晶原石后由当前铁匠提炼 |
| 千年纯金 | 技能装备材料 | 采集千年纯金原石后由当前铁匠提炼 |
| 千年魔菇 | `千年山参` 配方需要 30 个 | 当前 `Monster.sdb` 的“火王变身”掉落表 |

`比武北霸王.txt` 和 `比武东天王.txt` 都按随机分支在千年刚玉、千年神石之间选择，不能简化为“北霸王只给神石、东天王只给刚玉”。

## 云端千年神武奇章线上优化版参考

用户实际运营的云端神武版脚本能够证明该运营版本曾有以下来源；这些内容可能经过运营优化，不等同于原版神武奇章规则：

- `圆月老人*.txt` 的月魂兑换；
- `百宝箱.txt` 的宝箱奖励；
- 云端神武版 `比武赦龙组.txt` 奖励千年魔菇。

这些文件不在当前炎黄随包脚本索引中，炎黄版 `比武赦龙组.txt` 也没有千年魔菇奖励。因此上述来源不得写成当前炎黄获取方式；迁移时还必须同步检查 `Script.SDB`、物品名称、地图对象和对应 Help/NpcSetting 文件。
